# 行业研报处理：解读、翻译与摘要

依据用户提供的现成行业研报，解读原文并输出可独立阅读的结构化 Markdown 摘要，默认使用简体中文，也可按用户要求使用其他语言。以赛道、技术或产业链为主线，说明报告如何判断行业吸引力、关键瓶颈、竞争优势与变化方向，避免退化为几家公司的优缺点罗列。

这是研报处理技能，不是独立的行业研究技能：不根据一个行业名从零搜集资料、建立行业预测或选股框架，也不生成报告外的投资判断。

本文件可作为技能入口，也可直接与研报一起交给 AI。执行不依赖指定平台、模型、程序或发布渠道。

## 调用与交付形式

- **直接上传**：将本文件与研报放在同一对话中，并发送：“请按照这份文件的要求处理所附研报，输出完整中文摘要。”无需安装技能。用户已有明确处理请求且材料可读时，直接执行，不再询问是否开始或选择输出格式。
- **安装为技能**：在支持技能的工具中安装后，提供研报并明确调用 `hgs-industry-report-summary`，例如：“使用 hgs-industry-report-summary 处理所附研报。”技能的安装、选择和调用方式由所在工具决定，不能假定只上传 PDF 就会自动加载本文件。
- **默认交付**：在当前对话中直接输出完整 Markdown 摘要正文，不将全文包在代码块里。支持 Markdown 渲染的界面会显示标题、加粗、列表和表格；其他界面显示对应文本。默认不生成 HTML、附件或在线网址，也不依赖写文件能力。
- **Markdown 文件**：用户明确要求可下载或保存的 Markdown 时，环境支持文件生成就交付包含完整摘要的 `.md` 文件，并给出真实可用的文件入口；无法生成附件时说明限制，提供完整 Markdown 内容，不虚构文件或下载链接。
- **HTML 文件**：用户明确要求 HTML 或网页呈现时，交付包含完整摘要的单文件 `.html`，使用 UTF-8、内嵌样式和清晰的正文排版，兼顾桌面与手机阅读，不依赖外部资源。沿用本文件的章节、证据和口径要求，不增加报告外观点。环境支持文件生成时给出真实可用的文件入口，否则说明限制并以代码块提供完整 HTML 源码。HTML 文件是可在浏览器打开的文档，生成文件本身不产生在线网址。
- **多份报告**：默认每份报告各有一份完整摘要；用户要求文件时，每份独立成文件。只在用户明确要求合并时综合交付。

下文规定摘要内容与章节。用户明确要求文件或 HTML 时，仅改变交付形式，不省略摘要内容。

## 输入语言、翻译与输出语言

- 不限定报告机构或市场，不只适用于外资或英文研报。输入可为英文、中文或当前 AI 能可靠理解的其他语言；无法可靠读取或理解时，说明具体限制并请求可读材料，不声称支持所有语言。
- 默认用简体中文输出。用户明确指定英文、日文或其他语言时，全文、标题、来源声明、章节标题、表格标签和缺失信息提示使用该语言；保留章节含义、顺序与证据要求。下文中文模板是默认写法，不覆盖用户明确的语言要求。
- 输入与输出语言不同时，在理解原文与整理摘要的过程中完成忠实翻译。默认交付是翻译后的结构化摘要，不是整份 PDF 的逐字全文译本，也不先输出中间全文译稿或默认双语对照。不依赖指定翻译服务；逐段全文翻译或原 PDF 版式翻译需另行约定要求。
- 翻译不得改变否定、条件、比较对象、风险、预测语气或确定性；不得把“可能”“预计”等表达变成已发生事实。评级优先保留原文标签并给出译名，无法确认的译法标明疑义，不把评级标签自行归并为“买入”。
- 公司名、证券代码、产品名、技术名和必要缩写保留可回查的原文；术语可在首次出现时写译名并附原文。译名不等于补充定义，原文没有解释时仍注明“原文未解释”，不新增报告外背景。
- 数字、币种、单位、期间、技术工况和财务口径按原文核对；翻译不是汇率换算，不能因改用另一种语言就改变币种或数值。中文金额量级转换沿用下文规则；其他输出语言采用相应量级表达并核对换算。

## 输入与适用范围

- 必需输入：一份行业研报 PDF、报告截图或足以支撑摘要的报告正文。可附图表截图、表格转写或其他来源明确的补充材料。
- 适用于行业入门、技术路线综述、产业链梳理、行业专题和供需景气跟踪。报告可覆盖多家公司，但行业或技术应为主要研究对象。
- 若报告主要围绕单一公司、宏观经济、大类资产配置或量化模型，简要指出类型不匹配，请用户提供对应要求，不强套行业模板。
- 一次提供多份报告时，每份独立处理；只有用户明确要求综合时才合并，并逐项区分机构、日期与来源。

## 先确认材料可读

1. 使用当前环境具备的文件阅读、图像理解、文字识别或表格提取能力，读取正文与关键图表。PDF 的文字层可能缺少技术路线图、规格矩阵、份额表或供需图，不能据此认定报告没有这些内容。
2. 核对报告标题、机构、主要分析师、发布日期及原文件总页数。缺项写“未提供”或“未能确认”，不从文件名或惯例猜测。用户只提供截图或节选时，不将节选页数当成报告总页数。
3. 重点读取支撑市场规模、产业链节点、技术路线、玩家卡位、产品指标、供需、估值和风险的图表。核对行列、单位、工况、年份、实际或预测、脚注与正负号，不直接信任未经核对的识别文本。
4. 若无法访问报告内容，说明无法读取，并请求可读正文或相关页面，不生成摘要。若只读到节选或部分关键图表，可基于已读内容生成摘要，但在来源声明中明确覆盖范围和未能读取的关键部分，不声称完成全文分析。

## 证据与写作规则

- **报告证据边界**：正文、可读图表及来源明确的补充材料是本次摘要的事实依据。默认不检索外部资料，不补充报告未给出的公司、事件、年份、数字、背景或术语定义。用户明确要求外部研究时，将新增研究另列并注明来源，不伪装为报告内容。
- **观点与事实分开**：判断、预测及配置建议归属于报告，用“报告认为”“分析师预计”等表达。只罗列新闻或数据的材料，不扩写成原文未表达的看多、看空或推荐。
- **数字可回查**：具体产品规格、市场规模、份额、价格、目标价和排名必须来自实际读到的材料。缺失写“未披露”，无法读清写“未能可靠读取”。行业门槛、理想工况或通用值不能填入具体公司的产品数据。
- **完整指覆盖面**：保留报告的主要节点、路线、重点玩家、反方证据和风险，避免只选亮点；每条表述保持精炼，不逐页复述或重复堆数据。
- **定价权不同就分开**：按报告证据拆分扩产周期、切换成本、标准化程度和竞争格局明显不同的节点。报告缺少必要细分或公司信息时，标明缺口与其对判断的影响，不自行补写玩家、份额或结论。
- **看变化方向**：区分规模水平与增速、增速与增速的变化、短期订单与中长期技术替代；有时间轴和数据才描述方向，不根据静态高值推断景气继续加速。
- **口径分别标注**：区分财年 FY 与日历年 CY、实际值与预测值、含与剔除股权激励费用、GAAP 与调整后、P/E 与 EV 类倍数，以及市场规模的地域、产品范围与时间区间。不擅自换算财年。
- **技术工况明确**：性能、功率、温差、流量、压力、寿命和能耗等指标保留测试条件；名义值与实际工况、单机与系统、装机与实际运行不能混用。未披露条件就说明，不能把名义参数直接当作可比性能。
- **冲突不静默处理**：先核对期间、口径、币种、单位和工况。不同口径分开说明；同口径仍矛盾时，并列列出数值和来源，写明未能消解。不要按行业常识或预设数值改写原文，也不要因识别文本疑似错误就自动乘除十倍。
- **人物与身份**：姓名、职务、并购或标准制定方服从原文，不用记忆补上“正确背景”。必要时保留英文姓名。
- **以报告时点为准**：股价、目标价、上行空间、估值及份额说明所属期间，不包装成实时数据。报告未给出的上行空间、排名或估值结论不自行计算。
- **语言与单位**：默认简体中文，用户指定其他输出语言时遵循上节。保留必要的原文名、证券代码、技术及标准名。中文金额可转换为中文量级，但保留币种并核对换算；模糊量级保留为区间，不改成精确值。bps 在中文中写“个基点”，其他语言使用对应表达，百分比变化与百分点变化分开；技术单位保留并解释原文披露的含义。
- **保留有效信息**：忽略重复页眉页脚、联系方式、发行限制及法律披露等非研究内容；保留解释数字、假设、工况和风险的脚注，不一概删除脚注或表格。
- **形式**：用自己的话重组，只输出成品摘要，不附处理日志或自检过程。成品使用一级标题和二级小节标题，小节采用下列简短标题，不加数字编号或括号说明；条目优先用项目符号。
- **图表表达**：默认不嵌入原图，不使用必须跳转原图才能理解的“见图 X”指代。把关键图表的证据转为文字或精简 Markdown 表格；无法可靠读取的数据明确标注。来源页码可确认时，可在关键数字或争议后简短标注页码。

## 识别子类型

| 子类型 | 论证主线 | 一句话结论的切入点 |
|---|---|---|
| 行业入门或产业链梳理 | 驱动力、技术路线、价值链、竞争格局、未来变化 | 这条赛道是什么、为什么在当前受到关注、报告如何判断吸引力 |
| 行业专题 | 顺核心议题的论证，说明分歧、证据、受益或受损及风险 | 报告回应的争议与明确立场 |
| 景气或供需跟踪 | 供需、价格、产能、库存、订单、趋势及标的含义 | 当前周期位置以及紧缺或景气是否加剧、缓解 |

调整各节内部的观点顺序，以报告论证为准。产业链、竞争格局和变化方向都要检查；材料没有支撑时，保留相应小节并说明缺失，不为填模板编结论。

## 输出结构

按以下顺序输出。一级标题采用报告标题的目标语言表达，跨语言时在来源声明中保留原文报告标题供回查；原文标题不明时使用可确认的行业与议题，不编造标题。

来源声明放在标题后、小节前：

> 以下为 {机构} 的 {报告标题} 的结构化摘要。主要分析师：{姓名}；发布日期：{日期}；原文件总页数：{页数}。材料范围：{全文或已提供范围；必要时列出未能读取的关键部分}。

花括号字段按已确认信息填写；无法确认的字段明确写“未能确认”，不将示例占位符留在成品中。

### 🎯 一句话结论

用 2-4 句说明研究对象、报告的核心判断及最重要的变量或拐点。能从原文得出时，回答行业吸引力、瓶颈、谁可能赢及主要风险；未给出判断时说明，不用“本文讨论了某行业”代替结论，也不另造投资立场。

### 🔑 核心观点

通常约 3-7 条，随论点密度调整。每条采用“加粗结论标题 + 一段解释”，保留关键数字、方向、条件和逻辑。覆盖原文支持的行业定调、瓶颈、竞争优势、风险及技术替代，不只选择正面信息。

### 🗺️ 行业全景与产业链拆解

按材料组织三个层次：

- **驱动力与时点**：需求、成本、政策或技术变化为什么推动这一赛道；写出原文支持的因果链。
- **技术路线与赛道地图**：逐条说明报告覆盖的路线、定位、成熟度或份额；多条并行路径分开表达，不擅自当作顺序演进。
- **价值链节点**：逐节点说明功能、上下游关系、报告给出的定价权或护城河、成熟度或紧缺程度及关键路径属性。区分定价权结构不同的环节；原文未说明某项就明确缺失。

可用分层条目或紧凑文字表格建立结构，不把多个公司名称的列表当成产业链地图。

### 🏆 竞争格局与谁能赢

先给报告用于比较的标准、门槛与测试条件，再说明玩家在路线、客户、成本、认证、服务或产能上的卡位。提炼报告支持的“谁能赢、为什么”的判据，不根据产品规格单项高低直接推导长期胜者。

本节以竞争判断为主，避免逐家堆参数。但凡某项关键产品规格或对比矩阵直接支撑判断，应将必要的真实数据放入本节或“关键数据”的精简表格，并标明产品、单位及工况；只放一处，保证摘要可以独立理解。不复刻全部规格，不把“领先”之类标签当成数字证据。

若图表读不清，注明未能可靠读取的指标与受影响的判断，不出假表。没有可比口径或报告未给出胜者时，明确这一限制。

### 🔭 趋势·拐点·前瞻

区分现状与未来，说明原文支持的紧缺加剧或缓解、增速变化、份额迁移、下一代技术及兑现时点。不同路线和时间窗分别表达，避免近端订单利好掩盖远端替代风险。

列出报告明确提出、能证实或证伪判断的具体指标或事件，以及原文给出的时间或触发条件。只披露一般跟踪指标时就称其为跟踪指标，不虚构事件日期、阈值或二元验证结论；完全缺失时说明“报告未给出具体验证事件”。

### 📌 事实依据

一条一事，列支撑主要观点的可核事实或已披露数字，不夹入个人判断。注明期间、单位和来源口径。预测、管理层指引与行业标准不能写成已实现事实；确需收录时明确标注其性质。

### 📊 关键数据

根据报告重心选择市场规模及增长区间、份额、产能、价格、库存、订单、技术门槛或关键产品数据，保留相关假设。行业标准与具体产品实测数据分开呈现。预测注明年份、区间与基础情景；报告未给出的增速、排名和市场规模不自行推算。

采用“加粗指标名：数值”或精简文字表格。表格每格有材料依据，缺项留作“未披露”或“未能可靠读取”，不贴未经整理的整页数字。与竞争格局或涉及标的重复的数据只保留必要部分。

### 🧭 陈述总结

通常用 1-4 段连续散文，随报告体量调整，不用列表或表格。串联驱动力、路线或节点、竞争优势、变化方向及风险，收束报告最重要的判断和跟踪事项。

必须呈现原文风险或颠覆变量；原文没有具体风险时说明“报告未披露具体风险”，不补写报告外推断。

### 💼 涉及标的

列出报告重点分析或明确推荐的公司，注明公司名、证券代码、产业链位置、一句话卡位理由，以及原文披露的评级、目标价、报告时点股价、上行空间或估值口径。

区分推荐、重点覆盖、受益或受损判断与仅用于比较的公司。未评级、未推荐就如实标注，不因出现公司名而改写为买入建议。无需收录法律披露或分析师覆盖清单中与论证无关的公司。

### 🧩 专业名词及重要事件

优先选承载行业论证的技术、产品、标准、生态及事件。每项给出术语或事件、原文支持的通俗释义、在本报告中的作用。原文未解释的缩写保留原写法并注明“原文未解释”，不从记忆补标准发起方、并购年份或事件背景。

## 交付前自检

- 是否只在处理提供的研报，而没有扩展成独立行业研究？输出语言是否符合用户要求，翻译是否保留原文的否定、条件、评级及预测语气？
- 来源信息、原文件页数和材料覆盖范围是否有依据？
- 摘要是否呈现行业结构，而非只罗列公司的优缺点？
- 主要节点、并行路线与重点玩家是否保留，缺口是否如实说明而非自行补全？
- 竞争判断是否有可比证据，规格、行业门槛和不同测试工况是否分清？
- 关键图表是否读取，支撑结论的数据是否进入摘要，未读到的是否明确标注？
- 数字、单位、期间和财务口径是否可回查，冲突是否带来源并列呈现？
- 静态水平、变化方向、短期与中长期、事实与预测是否分清？
