# 公司研报处理：解读、翻译与摘要

依据用户提供的现成公司研报，解读原文并输出可独立阅读的结构化 Markdown 摘要，默认使用简体中文，也可按用户要求使用其他语言。提炼报告的观点、证据和风险，让读者理解报告为什么看好或看空该公司。

这是研报处理技能，不是独立的公司研究技能：不根据一个公司名从零搜集资料、建立盈利预测或估值模型，也不生成报告外的投资判断。

本文件可作为技能入口，也可直接与研报一起交给 AI。执行不依赖指定平台、模型、程序或发布渠道。

## 调用与交付形式

- **直接上传**：将本文件与研报放在同一对话中，并发送：“请按照这份文件的要求处理所附研报，输出完整中文摘要。”无需安装技能。用户已有明确处理请求且材料可读时，直接执行，不再询问是否开始或选择输出格式。
- **安装为技能**：在支持技能的工具中安装后，提供研报并明确调用 `hgs-company-report-summary`，例如：“使用 hgs-company-report-summary 处理所附研报。”技能的安装、选择和调用方式由所在工具决定，不能假定只上传 PDF 就会自动加载本文件。
- **默认交付**：在当前对话中直接输出完整 Markdown 摘要正文，不将全文包在代码块里。支持 Markdown 渲染的界面会显示标题、加粗、列表和表格；其他界面显示对应文本。默认不生成 HTML、附件或在线网址，也不依赖写文件能力。
- **Markdown 文件**：用户明确要求可下载或保存的 Markdown 时，环境支持文件生成就交付包含完整摘要的 `.md` 文件，并给出真实可用的文件入口；无法生成附件时说明限制，提供完整 Markdown 内容，不虚构文件或下载链接。
- **HTML 文件**：用户明确要求 HTML 或网页呈现时，交付包含完整摘要的单文件 `.html`，使用 UTF-8、内嵌样式和清晰的正文排版，兼顾桌面与手机阅读，不依赖外部资源。沿用本文件的章节、证据和口径要求，不增加报告外观点。环境支持文件生成时给出真实可用的文件入口，否则说明限制并以代码块提供完整 HTML 源码。HTML 文件是可在浏览器打开的文档，生成文件本身不产生在线网址。
- **多份报告**：默认每份报告各有一份完整摘要；用户要求文件时，每份独立成文件。只在用户明确要求合并时综合交付。

下文规定摘要内容与章节。用户明确要求文件或 HTML 时，仅改变交付形式，不省略摘要内容。

## 输入语言、翻译与输出语言

- 不限定报告机构或市场，不只适用于外资或英文研报。输入可为英文、中文或当前 AI 能可靠理解的其他语言；无法可靠读取或理解时，说明具体限制并请求可读材料，不声称支持所有语言。
- 默认用简体中文输出。用户明确指定英文、日文或其他语言时，全文、标题、来源声明、章节标题、表格标签和缺失信息提示使用该语言；保留章节含义、顺序与证据要求。下文中文模板是默认写法，不覆盖用户明确的语言要求。
- 输入与输出语言不同时，在理解原文与整理摘要的过程中完成忠实翻译。默认交付是翻译后的结构化摘要，不是整份 PDF 的逐字全文译本，也不先输出中间全文译稿或默认双语对照。不依赖指定翻译服务；逐段全文翻译或原 PDF 版式翻译需另行约定要求。
- 翻译不得改变否定、条件、比较对象、风险、预测语气或确定性；不得把“可能”“预计”等表达变成已发生事实。评级优先保留原文标签并给出译名，无法确认的译法标明疑义，不把评级标签自行归并为“买入”。
- 公司名、证券代码、产品名、技术名和必要缩写保留可回查的原文；术语可在首次出现时写译名并附原文。译名不等于补充定义，原文没有解释时仍注明“原文未解释”，不新增报告外背景。
- 数字、币种、单位、期间和财务口径按原文核对；翻译不是汇率换算，不能因改用另一种语言就改变币种或数值。中文金额量级转换沿用下文规则；其他输出语言采用相应量级表达并核对换算。

## 输入与适用范围

- 必需输入：一份研报 PDF、报告截图或足以支撑摘要的报告正文。可附图表截图、表格转写或其他来源明确的补充材料。
- 核心对象应为单一公司，内容围绕公司评级、估值、经营、盈利或投资判断。若主要对象实际是行业、宏观或量化策略，简要指出类型不匹配，请用户提供对应要求，不强套公司模板。
- 一次提供多份报告时，每份独立处理；只有用户明确要求综合时才合并，并逐项区分机构、日期与来源。

## 先确认材料可读

1. 使用当前环境具备的文件阅读、图像理解、文字识别或表格提取能力，读取正文与关键图表。PDF 有文字层不代表表格和图片内容已经读到。
2. 核对报告标题、机构、主要分析师、发布日期及原文件总页数。缺项写“未提供”或“未能确认”，不从公司名、文件名或惯例猜测。原文件总页数与印刷页码可能不同；用户只提供截图或节选时，不将节选页数当成报告总页数。
3. 阅读支持评级、目标价、财务预测、分部经营、估值和风险的内容。表格需核对行列、年度、币种、单位、脚注与正负号，不直接信任未经核对的识别文本。
4. 若无法访问报告内容，说明无法读取，并请求可读正文或相关页面，不生成摘要。若只读到节选或部分关键图表，可基于已读内容生成摘要，但在来源声明中明确覆盖范围和未能读取的关键部分。

## 证据与写作规则

- **报告证据边界**：正文、可读图表及来源明确的补充材料是本次摘要的事实依据。默认不检索外部资料，不补充报告未给出的评级、事件、数字、背景或术语定义。用户明确要求外部核验时，核验结果另列，不混入报告原有观点。
- **报告观点与事实分开**：判断、预测、评级与建议标为“报告认为”“分析师预计”等；已披露经营数据与发生的事件作事实陈述。不得把新闻汇总或事实罗列扩写为报告没有表达的投资结论。
- **数字可回查**：数字来自实际读到的正文或图表。缺失写“未披露”，无法读清写“未能可靠读取”；不得以常识、估算、行业门槛或示例填空。
- **人物与身份**：涉及分析师、管理层、监管或政策人物时，姓名与职务服从原文；必要时保留英文姓名，不按记忆替换为其他现任或前任。
- **口径分别标注**：区分财年 FY 与日历年 CY、实际值与预测值、GAAP 与调整后、含股权激励费用与剔除股权激励费用、毛利率与营业利润率及净利率、P/E 与 EV 类倍数。不擅自换算财年；原文明确披露映射关系时才写出对应关系。
- **比较对象明确**：区分旧预测与新预测、公司指引与分析师预测及市场共识。只在原文提供可比基准时写“超预期”“上修”或变化幅度，不自行补基准。
- **冲突不静默处理**：同一指标先核对期间、口径、币种与单位。口径不同就分开说明；相同口径仍矛盾，就并列列出数值和各自来源，写明未能消解，不擅自纠错。
- **以报告时点为准**：股价、上涨空间、评级、预测与目标价均注明报告日期或原文明确给出的基准日期，不包装成实时数据。不自行计算原文未给出的上行空间或估值结论。
- **语言与单位**：默认简体中文，用户指定其他输出语言时遵循上节。保留必要的公司原文名、技术名词和证券代码。中文金额可转换为中文量级，但保留币种并核对换算；bps 在中文中写“个基点”，其他语言使用对应表达，百分比变化与百分点变化分开。保持原文精度，保留近似、区间和条件。
- **保留有效信息**：忽略重复页眉页脚、发行限制、联系方式和法律披露等非研究内容；保留解释数字、口径、假设和风险的脚注，不一概删除脚注或表格。
- **形式**：用自己的话重组。观点通常约 3-7 条，综述通常 1-4 段，随报告体量调整。只输出成品摘要，不附处理日志或自检过程。成品使用一级标题和二级小节标题，小节采用下列简短标题，不加数字编号或括号说明；条目优先用项目符号。
- **图表表达**：默认不嵌入原图，不使用必须跳转原图才能理解的“见图 X”指代。真实财务、估值或分部数据可用精简 Markdown 表格表达；正文必须保留支撑结论的关键数字。来源页码可确认时，可在关键数字或争议后简短标注页码。

## 识别子类型

| 子类型 | 主要观点的组织顺序 | 陈述总结的开头 |
|---|---|---|
| 评级变动或首次覆盖 | 评级与目标价变化、行业供需、竞争与公司优势、催化剂、风险 | 评级及目标价；旧值、变动与上行空间仅在原文披露时列出 |
| 专题深度 | 顺报告论证主线，突出核心争议、证据、公司差异和风险 | 核心议题、报告立场及评级 |
| 财报点评 | 业绩与预期或指引差异、盈利预测、分部、估值与风险 | 当期结果、比较基准及评级或目标价变化 |

根据报告重心调整各节内部的观点顺序；以核心结论开场，并在综述结尾收束评级或风险收益判断。重申评级不写成评级变化。

## 输出结构

按以下顺序输出。一级标题采用报告标题的目标语言表达，跨语言时在来源声明中保留原文报告标题供回查；原文标题不明时使用可确认的公司名与议题，不编造标题。保留各节，缺少实质材料时用一句话说明未披露。

来源声明放在标题后、小节前：

> 以下为 {机构} 的 {报告标题} 的结构化摘要。主要分析师：{姓名}；发布日期：{日期}；原文件总页数：{页数}。材料范围：{全文或已提供范围；必要时列出未能读取的关键部分}。

花括号字段按已确认信息填写；无法确认的字段明确写“未能确认”，不将示例占位符留在成品中。

### 🎯 主要观点

每条使用“加粗结论标题 + 一段解释”，保留关键数字、比较基准和因果链。按子类型组织，突出报告最重要的判断。报告单列风险时，可将风险作为独立观点，同时在陈述总结中呈现。

### 📌 事实依据

一条一事，收录支持主要观点的已披露数据或可核事实，不夹入个人判断。数字注明期间、单位和来源口径。报告预测与指引主要放入关键数据；确需引用时，明确标为预测或指引，不能写成已实现事实。

### 🧭 陈述总结

用连续散文串联核心议题、盈利或经营证据、公司优势、估值及风险，不用列表或表格。必须呈现原文风险；原文没有具体风险时，说明“报告未披露具体风险”，不补写报告外推断。结尾收束报告的评级、目标价或风险收益判断。

### 📊 关键数据

按报告重心选择评级与目标价、财务预测、利润率、现金流、回报效率、份额、产能、价格、订单或分部数据。优先保留支持论点的旧值与新值、实际值与预测值、共识与指引比较；缺少其中一项不补齐。

使用“加粗指标名：数值”，多期间或多分部比较可用文字表格。表格中的每格数据必须有材料依据，不展示未经整理的整页数字。

### 💼 推荐资产标的

逐一列出报告明确推荐或给予评级的公司：公司名、证券代码、评级、目标价、报告时点股价及上行空间、估值方法、一句话理由。只保留原文披露的字段。

提及同行用于比较，不代表推荐。对这类公司注明“比较对象，未给出推荐”，不虚构评级；原文未提出推荐时直接说明。

### 🧩 专业名词及重要事件

优先选承载报告论证的技术、产品、业务分部、估值口径和事件。每项给出术语或事件、原文支持的通俗释义、在本报告中的作用。原文未解释的缩写保留原写法并注明“原文未解释”，不从记忆补定义或事件背景。

## 交付前自检

- 是否只在处理提供的研报，而没有扩展成独立公司研究？输出语言是否符合用户要求，翻译是否保留原文的否定、条件、评级及预测语气？
- 来源信息是否有依据，材料覆盖范围是否如实说明？
- 子类型、观点顺序和综述开头是否匹配报告重心？
- 观点、预测、指引与已实现事实是否分清，推荐与同行比较是否分清？
- 数字是否能回查，期间、币种、单位、精度、财年及财务口径是否正确？
- 关键图表是否读取，未读到的数据是否明确缺失，冲突是否带来源并列说明？
- 原文风险、主要论证及估值依据是否保留，是否补入了报告外的信息？
- 摘要能否脱离原图理解，所有占位符是否已替换，是否仅输出成品正文？
