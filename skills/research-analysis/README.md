# 研究分析

**[Haoge Truth · 浩哥的真话圈](https://x.com/haogetruth)** · [返回总目录](../../README.md)

我是 [浩哥 / @haogetruth](https://x.com/haogetruth)。我把平时常用的信息处理、研究分析框架和具体要求，都整理成了这些 skill。这样每次都能直接复用，不用重新解释一遍，也能让产出的结构和质量更稳定。

你可以搭配自己的 AI Agent 来用。做信息处理时，把自己的材料和对应的 skill 一起给 AI。目前的信息处理技能主要用于研报，建议优先用正规机构发布、内容完整清晰的报告，方便 AI 提取观点、数据和证据。

做研究分析时，可以给一个想研究的 idea、想了解的行业，或者一家公司，再把对应的 skill 一起交给 AI，让它按框架查找资料、展开分析。

## 这一组做什么

这里是从研究问题出发，让自己的 AI 查资料、分析公司或行业，再把证据和判断整理成报告。

不需要先准备一整份研报。你可以只告诉 AI 想研究什么、重点想弄清哪些问题；有财报、公告、研报等有权使用的资料，也可以一起附上。只是想整理一份现成研报的话，去 [信息处理](../information-processing/README.md)。

每份 `SKILL.md` 都是完整的操作手册，不是简版介绍：研究维度、必查数据、表格字段、图表规格、写作要求和定稿核查都在同一个文件里。直接使用时，把整份文件交给 AI 就行，不需要另外找一份隐藏模板。

## 选哪个

| 技能 | 名称 | 主要做什么 |
|---|---|---|
| [公司深度研究](hgs-company-deep-research/SKILL.md) | `hgs-company-deep-research` | 研究一家公司的行业位置、竞争、客户、护城河、财务、战略与估值 |
| [行业深度研究](hgs-industry-deep-research/SKILL.md) | `hgs-industry-deep-research` | 拆赛道与商业模式，比较公司能力、兑现路径、资金与情景空间，给出有依据的评分和排序 |

两份都能单独使用，选你需要的就好。报告里的评分是基于证据的研究判断，不是统计意义上的胜率；理想情景下的空间，也不等于收益保证或确定的目标价。

## 直接用

把对应的 `SKILL.md` 放进 AI 对话，再给任务，例如：

> 请按公司深度研究技能研究【公司全称、证券代码与市场】，重点看【核心问题】，生成中文 HTML 报告。

> 请按行业深度研究技能研究【赛道】，覆盖【公司列表】，比较经营兑现与融资压力，生成中文 HTML 报告。研究截至日用本次实际取数时间。

有相关附件就一起提供。平台不支持上传 Markdown，直接粘贴文件全文也行。没有安装技能时，换一个新对话要重新提供文件；支持安装的 AI Agent，也可以安装后反复调用。

## 数据和工具

如果你的 AI 已经能访问获授权的 Wind、iFinD、行情工具或数据库，就让它优先尝试这些来源。用不了时，再找监管披露、交易所、公司投资者关系网站、官方统计等公开资料，并说明数据口径和缺了哪些信息。

不用为了这个技能专门购买指定终端，也不用把账号、密码或 API Key 发给我。不过，AI 要能联网查资料、读取材料；没有联网能力时，只能依据你提供的资料做分析，并说明范围限制。查不到的关键数据就写清楚，不能凭记忆编最新数字，也不能为了填表或评分硬凑答案。

图表也不必依赖某一个工具。ECharts 能用就用；网络或工具受限时，可以换本地可用的库、静态图或完整表格。如果 AI 没有浏览器验证工具，就应该说明没做页面截图和交互检查，而不是说已经测试过。

## 默认输出

两份默认都是中文 HTML 报告，包含完整章节、图表或数据表、资料来源、研究截至日、风险与免责声明。行业版还会在对话里给一份简短摘要；公司版的核心结论放在报告里。

AI 能生成附件时，会给你实际的 `.html` 文件；不能生成时，就说明限制并给出完整 HTML 源码，不应该给一个不存在的下载链接。HTML 可以在浏览器里打开，但不会自动发布成网站。需要离线阅读时，可以直接说“不要依赖外部资源”。

你也可以要求 Markdown、长文或其他语言。换的是呈现方式，研究结构和证据要求不变；实际能做到什么程度，还是取决于你用的 AI。

HTML 最后默认留一行低调的 `Powered by @haogetruth`，没有顶部品牌行、二维码、平台列表或社群宣传。你也可以说“报告不要署名”，让 AI 去掉它。这行只是说明所用技能的来源，不代表报告由我撰写、审阅或背书。其他格式默认不加这行。

## 下载与安装

到 [最新下载页](https://github.com/haogetruth/haoge-skills/releases/latest)，选你需要的独立 ZIP。文件名里的版本号以下载页为准：

- 公司版：`hgs-company-deep-research`
- 行业版：`hgs-industry-deep-research`

每个 ZIP 里只有一个同名技能目录，包含 `SKILL.md` 和 `LICENSE`，按你用的工具导入即可。不另做合并安装包；想一次拿到全部文件，可以用仓库首页的 `Code > Download ZIP`。

Codex 的 skill-installer 可使用：

```text
仓库：https://github.com/haogetruth/haoge-skills
公司版：skills/research-analysis/hgs-company-deep-research
行业版：skills/research-analysis/hgs-industry-deep-research
```

安装后，告诉 AI 用哪个技能、做什么任务就行。分类目录只是方便查找，不是需要额外安装的技能。

## 使用边界

研究只使用有权访问的材料，不绕过登录或付费限制。这些技能不会操作交易，也不会自动发送报告。AI 仍可能读错数字、时间和图表，重要判断要回查原材料。

报告用来辅助学习和研究，不是个性化交易建议。公开反馈时，用脱敏片段说明问题就好，不要上传私人持仓、账号或未公开资料。
